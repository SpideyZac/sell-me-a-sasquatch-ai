Sell Me a Sasquatch - AI

For an actual live (physical) game. It's still the real rules engine underneath - so collections, point totals, discard/draw piles, and set trade-ins are all handled for you automatically and correctly - but nothing is dealt randomly. You just enter each card's real identity exactly when it becomes visible at the table (your starting hand, then anything as it's revealed); the advisor ranks your own decisions along the way.
